## 1. 主窗口整体布局

主窗口采用 **Tab 页**结构，两个页签：**运行**（状态 + 操作 + 日志）与 **设置**。

```
┌────────────────────────────────────────────────────────────────┐
│  ● AstesiaHarness — DeepSeek Harness 快速启动器     [—][□][×]  │
├────────────────────────────────────────────────────────────────┤
│  状态条： ● Running（绿）  URL: http://127.0.0.1:3080 [复制]    │
│          PID: 12345 · 已运行 00:03:12 · 端口 3080               │
├────────────────────────────────────────────────────────────────┤
│  [▶ 启动]  [■ 停止]  [↻ 重启]  [🌐 打开浏览器]                  │
├────────────────────────────────────────────────────────────────┤
│  ┌─ 运行 │ 设置 ────────────────────────────────────────────── │
│  │  ┌ 日志（stdout 黑色 / stderr 红色，时间戳前缀）            │
│  │  │  [清空] [复制] [☑ 自动滚动]                              │
│  │  │  ...                                                     │
│  │  └───────────────────────────────────────────────────────  │
│  └────────────────────────────────────────────────────────────  │
└────────────────────────────────────────────────────────────────┘
```

> "设置"页签承载全部配置项（见 3.3），与"运行"页签平级切换。

## 2. 显示的信息

| 区域 | 信息 | 显示时机 |
| --- | --- | --- |
| 标题栏 | 应用名 + 窗口图标（app.ico） | 始终 |
| 状态条 | 状态徽标：● Stopped（灰）/ Starting（橙）/ Running（绿）/ Failed（红） | 始终 |
| 状态条 | 服务 URL（可点击打开） | Running 时 |
| 状态条 | 进程 PID | Starting / Running / Failed 时 |
| 状态条 | 已运行时长（每秒刷新） | Running 时 |
| 状态条 | 当前端口 | 始终（取设置值） |
| 日志区 | 子进程 stdout / stderr 滚动输出（时间戳 + 来源着色） | 有输出时 |
| 设置区 | 当前生效的配置项值（仓库路径、端口、主机、附加参数等） | 始终 |
| 底部提示 | 最近一次错误/操作反馈（如"端口被占用"、"已停止"） | 事件发生时 |

## 3. 包含的功能

### 3.1 操作按钮（按状态启用/禁用）

| 按钮 | 可用状态 | 行为 |
| --- | --- | --- |
| ▶ 启动 | Stopped / Failed | 走完整启动流程：端口探测 → 拉起进程 → 等待就绪 → （自动开浏览器） |
| ■ 停止 | Starting / Running | 终止整个进程树（Job Object），回到 Stopped |
| ↻ 重启 | Running | 先停止再启动 |
| 🌐 打开浏览器 | Running | 调起默认浏览器打开当前 URL（等效"手动开浏览器"） |
| 复制 URL | Running | 复制 URL 到剪贴板 |

### 3.2 日志区功能

- 实时滚动显示 stdout / stderr（stderr 红色区分）；
- 工具栏：清空日志、复制全部、自动滚动开关；
- 环形缓冲 5000 行（与 requirements FR-6 一致）。

### 3.3 设置页签（Tab 页，保存后写入 settings.json）

| 设置项 | 控件 | 说明 |
| --- | --- | --- |
| DSH 仓库路径 | 文本框 + [浏览…] | 默认 `F:\Codes\DownloadProjects\deepseek-harness` |
| 端口 | 数字输入 | 默认 3080，透传 `--port` |
| 主机 | 下拉（127.0.0.1 默认） | 透传 `--host`；DSH 拒绝 0.0.0.0，界面不给该选项 |
| 附加参数 | 文本框 | 追加到命令尾部，如 `--trusted-host lab.internal` |
| 自动打开浏览器 | 开关 | 默认开 |
| 关闭窗口时最小化到托盘 | 开关 | 默认开 |
| 开机自启 | 开关 | 写/删 HKCU Run 键，启动参数 `--minimized` |
| [保存] [恢复默认] | 按钮 | 保存后若服务在跑，提示"参数重启后生效" |

### 3.4 托盘（主窗口之外，一并确认）

- 图标：**app.ico 原图**（不加状态色角标），状态通过 **tooltip 文字** 表达（如 `AstesiaHarness — Running · http://127.0.0.1:3080`、`Stopped`、`Starting…`、`Failed`）；
- 左键单击：显示/聚焦主窗口；
- 右键菜单：打开浏览器 / 启动 / 停止 / 重启 / 显示主窗口 / 退出；
- 托盘"退出"且服务在跑时：弹出确认"是否同时停止 DSH Web 服务？"。

### 3.5 其他行为

- 单实例：重复启动只聚焦已有窗口；
- 窗口右上角 ×：按设置最小化到托盘（不退出）；
- 启动失败（如端口被占、pnpm 缺失）：状态转 Failed + 底部提示 + 日志尾部可查，不崩溃。

## 4. 已确认决策（2026-02）

| 项 | 决策 |
| --- | --- |
| 主窗口信息与功能 | 按本规格实现，无增减 |
| 设置区形式 | **独立 Tab 页**（运行 / 设置） |
| 托盘"退出"时对运行中服务 | **保留二次确认**（是否同时停止服务） |
| 托盘状态色 | **不加角标**：图标恒为 app.ico 原图，状态靠 tooltip 文字 + 主窗口状态条表达 |
