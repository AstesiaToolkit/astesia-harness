# Assets — 图标资源

## 主图标（必需）

把你自己准备的图标文件放到：

```
AstesiaHarness/Assets/app.ico
```

该文件是**唯一图标源**，三处共用：

| 用途 | 加载方式 |
| --- | --- |
| exe 图标（资源管理器 / 任务栏） | csproj `<ApplicationIcon>` |
| 主窗口标题栏图标 | 嵌入资源 pack URI |
| 托盘图标 | `Icon.ExtractAssociatedIcon(exe)` 或嵌入资源流 |

## 格式要求（建议）

- 文件格式：`.ico`（多帧图标容器）；
- 建议内嵌多分辨率：**16×16、32×32、48×48、256×256**；
  - 16×16 → 托盘（任务栏通知区）；
  - 32×32 → 任务栏；
  - 48×48 / 256×256 → Alt+Tab、资源管理器大图标。
- 若你只有 PNG：可用本项目后续提供的 `scripts/png-to-ico.ps1` 转换（或任选在线转换工具，选"多尺寸 ICO"）。

## 变更流程

替换文件后重新 `dotnet build` 即可生效；无需改代码。
